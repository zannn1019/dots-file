════════════════════════════════════════════════════════════════════════════
  KEY IMPLEMENTATION NOTES
════════════════════════════════════════════════════════════════════════════

1. Z-INDEX IS CRITICAL
   ✓ Entering workspace MUST have higher z than exiting
   ✗ Don't rely on render order - explicitly set z values
   
2. STATE TRACKING
   ✓ Track both current AND previous workspace IDs
   ✗ Don't assume only "active" state - need transitional states
   
3. SPRING PHYSICS
   ✓ Use SpringAnimation, not NumberAnimation with easing
   ✗ Don't use easing.type: Easing.OutBack as spring substitute
   
4. PARTIAL EXIT
   ✓ Old workspace slides to -20%, not -100%
   ✗ Don't make it disappear completely - keeps context
   
5. CLIP BOUNDARIES
   ✓ Parent container needs clip: true
   ✗ Otherwise workspaces render outside bounds during transition

6. CANVAS REFRESH
   ✓ Call requestPaint() when colors/state change
   ✗ Canvas won't auto-update on property changes
